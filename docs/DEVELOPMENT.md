## 新功能接入

1. 从 [设计规格](superpowers/specs/2026-11-21-travel-multi-agent-design.md) 和 [架构](ARCHITECTURE.md) 确认状态、权限、依赖及验收边界。为每个用户入口定位真实代码和业务存储。
2. 在现有 `runtime.py` 或正式工作流/工具模块上增量扩展。复用身份与所有权查询、`ToolRegistry`、`ToolExecutor`、请求 ID 和错误契约。涉及 PostgreSQL 结构的迁移先验证旧数据和重跑行为。
3. 测试成功、失败和并发情形。必要时增加隔离 schema 的集成测试。收费调用使用明确授权、超时和配额，优先使用沙箱，禁止以测试调用真实订单或外部预订。
4. 运行 [RUNBOOK](RUNBOOK.md) 中的回归与真实 HTTP 验收。检查数据库数据变化、异常响应、日志、重启恢复。分别记录 PASS、FAIL、BLOCKED，并保留命令或脚本入口。
5. 更新 README 与受影响的运行、故障或架构文档。提交前用 `git status --short`、`git diff --check` 检查范围与格式，显式暂存文件。提交中排除本地配置、密钥、数据库内容和临时探针输出。
